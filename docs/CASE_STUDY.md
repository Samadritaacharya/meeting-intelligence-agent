# Case Study: Meeting Intelligence Agent

## Context

Project, PMO, operations, and leadership meetings often create a large amount of unstructured information. Without clear follow-up, decisions, risks, owners, and deadlines can become difficult to track.

## Problem

Meeting notes are usually not enough for project execution. Teams need structured outputs that can be reused for:

- executive summaries
- action tracking
- risk registers
- Jira tasks
- follow-up emails
- project documentation

## Solution

Meeting Intelligence Agent converts a transcript into PMO-ready outputs using Claude API or demo fallback mode. It supports multiple meeting templates, including project sync, steering committee, incident review, sprint planning, vendor discussion, and stakeholder workshop.

## Features delivered

- Meeting type / PMO template selector
- Executive summary
- Key decisions
- Action-item table with owner, action, due date, priority, and status
- Risk register with impact, likelihood, mitigation, and owner
- Open questions
- PMO status with RAG status and decision needed
- Follow-up email draft
- PDF, DOCX, Jira CSV, risk CSV, and Markdown exports

## Skills demonstrated

- AI workflow design
- PMO process understanding
- Prompt engineering
- Structured JSON handling
- Executive communication
- Secure secret management
- Exportable documentation
- Streamlit app development

## Relevance to target roles

This project is relevant for roles in technical project management, PMO, AI transformation, cloud operations, product operations, and digital transformation because it shows how AI can support practical project execution workflows.
