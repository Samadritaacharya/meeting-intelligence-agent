# Meeting Intelligence web design

The public command center uses dark editorial surfaces, warm orange/coral accents, restrained glass, and a flowing R3F system map to visualize how unstructured conversation becomes accountable work.

Taste Skill informs the audit-first hierarchy; awesome-design-md informs explicit design constraints; ShaderGradient supplies low-density ambience; liquid-glass-js is visual inspiration only; liquid-logo inspires the shader concept only. The center orb is original GLSL. Motion honors reduced-motion, WebGL has a fallback, and no paid API, model key, DB, login, or analytics service is required.
